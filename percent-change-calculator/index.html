Percent Change Calculator

Calculate the percent change between two values instantly with a simple calculator, clear formula, and worked examples.

Calculator inputs

Enter an original value and a new value to calculate the percentage change instantly.

Starting value before the change. It can be money, units, scores, or any comparable number.

Value after the change. Use the same unit as the original value.

Controls rounding in the displayed result only; it does not change the underlying calculation.

Result
Enter a value to begin

Formula

percent change = ((new value - original value) ÷ original value) × 100

Example: from 80 to 100 = 25.000%

Worked examples

From 80 to 100 = 25.000%

From 50 to 45 = -10.000%

From 200 to 260 = 30.000%
