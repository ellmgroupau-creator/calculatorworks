Epley estimate

For more than one completed repetition, estimated 1RM = weight × (1 + repetitions ÷ 30). This tool accepts 1–12 whole repetitions; one repetition returns the entered weight. At 85 kg for 5 repetitions, the estimate is 99.17 kg. Use the same weight unit throughout.

An estimate, not a lifting instruction

Technique, exercise choice, fatigue and how close the set was to failure affect the result. It is not a guarantee that you can lift the estimated weight. Use appropriate supervision and do not attempt a maximum solely because of a calculator result.
