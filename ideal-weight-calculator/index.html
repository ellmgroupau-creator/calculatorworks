A reference weight, not an ideal target

Calculate a height-based reference weight using BMI 22 and an optional manual percentage adjustment. This is not an individual ideal-weight recommendation.reference weight (kg) = 22 × height (metres)². It does not use the Devine equation. A single height-based number cannot determine the healthiest weight for an individual.

What the adjustment means

The optional adjustment changes the calculated reference by your chosen percentage: adjusted weight = reference weight × (1 + adjustment ÷ 100). It is a manual scenario input, not a validated measurement of body frame. Leave it at 0% for the unadjusted reference.

Worked example

At 175 cm, the unadjusted reference is 22 × 1.75² = 67.38 kg. A 5% adjustment gives 70.74 kg. These are mathematical reference values, not a recommended weight range or a diagnosis.

Limits of height-based estimates

This adult reference ignores body composition, pregnancy, age-related changes and clinical history. Do not use it for children or set a weight-loss goal from it alone. Discuss individual concerns with a qualified health professional.
