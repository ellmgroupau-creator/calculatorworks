Calculadora de média

Use esta ferramenta para calcular rapidamente com fórmulas claras, exemplos resolvidos e ligações relacionadas.

Dados da calculadora

Introduza os valores necessários para obter o resultado imediatamente.

Introduza cada número separado por vírgula, por exemplo 4, 8, 12.

Controla apenas o arredondamento apresentado; não altera o cálculo interno.

Resultado
Introduza um valor para começar

Fórmula

média = soma de todos os números ÷ contagem de números

Exemplo: (10 + 20 + 30) ÷ 3 = 20.000

Exemplos resolvidos

10, 20, 30 → Média = 20,000

5, 15, 25, 35 → Média = 20,000

72, 85, 91, 68, 77 → Média = 78,600

Guia da calculadora
